## Что это

Магазин сессий на браузерные мини-игры. Пользователь покупает токен и получает ссылку с доступом к игре. В магазине мои игры с курсов RS School и несколько выдуманных, сгенерированных нейросетью, чтобы лучше показать идею.

Стек: TypeScript, Vite, Vitest, Firebase (Auth, Firestore), собственный SPA-роутер, деплой на GitHub Pages.

## Что делала я

- **Страница каталога.** Сетка карточек, пагинация, фильтр по жанрам. Страница и жанр хранятся в URL (`?page=2&category=puzzle`). Загрузка данных игр и преобразование из Firestore, состояния загрузки, ошибки и пустого списка.
- **Интерфейс.** Шапка, подвал, карточка игры, детальная карточка игры.
- **Основа проекта.** Настройка инструментов (eslint, prettier, husky), дизайн-токены тёмной темы, типизированный `createElement`, URL-хелперы.
- **Доступность и дизайн.** Навигация с клавиатуры, видимый фокус, области нажатия от 44 px, контраст по WCAG AA, `prefers-reduced-motion`. Переделка дизайна по DESIGN.md: в CSS только токены.
- **Данные.** Моковый каталог, изображения, данные карточек.
